Errors and limits
Zod rejects invalid input with BAD_REQUEST. Stale transitions report CONFLICT; missing workflows return NOT_FOUND; AI setup errors use PRECONDITION_FAILED; model failures use BAD_GATEWAY.
Workflow and run pages default to 25 records (maximum 50). They return { items, nextCursor }. Event pages return up to 50 entries and use an exclusive before event-ID cursor. No million-user throughput claim is made.
